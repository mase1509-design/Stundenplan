# Stundenplan – Simon & Luisa

Statische PWA für GitHub Pages. Kein Backend und keine externen Dienste.

## Nutzung
1. Dateien in ein GitHub-Repository hochladen.
2. GitHub Pages für den Branch/Ordner aktivieren.
3. Die Seite auf iPhone oder Android öffnen und zum Home-Bildschirm hinzufügen.

Simon nutzt Grün, Luisa Hell-Lila. Die aktuelle Stunde wird anhand der Gerätezeit automatisch hervorgehoben.
